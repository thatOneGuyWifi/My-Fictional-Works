I'd decided I'll have my own rule on how to use punctuation mark. I made this document to clearly layout the rules, use it as reference and update the rules as I go.

---

**Comma (,)**: Use it when two or more clauses (independent of type) are related in a sub-topic, in lists or list-like sentences or when directly addressing someone.

**Semicolon (;)**: Use it when adding supplementary/optional information that is related to the sub-topic at the end or in sub-lists (a list inside a list: A,B,C;D,E,F;G,H,I 3 sub-list inside one list separated by two semicolons).

**Colon (:)**: Use it when two clauses follow "cause and effect", conditional statements (if/when/for/etc x:) or when listing characteristics/properties of a subject/object.

**Period (.)**: Use it when ending a sub-topic (but the main topic continues), main topic or for initials.

**Ellipsis (...)**: Use it when in need of a long pause (that doesn't end the sub-topic) or when leaving out information.

**Hyphen (-)**: Use it in when joining two words together to make one word (a combined word), showing ranges or when assigning a quote to someone.

**Parenthesis (())**: Use it when adding optional information to words, clauses, sentences, paragraphs or anywhere in a topic or when you need to insert optional information.

**Square Brackets ([])**: Use it when adding optional information inside a parenthesis or when you need to insert required information.

**Curly Brackets ({})**: Use it when adding optional information inside a square bracket (if you need to add parenthesis inside curly brackets, it loops back to normal parenthesis).

**Em-dash (—)**: Use it when a clause/information is interrupted or use it like a parenthesis but it's more important/relevant to the sub-topic (level of importance can be decided by the writer).

**Slash (/)**: Use it as a "or"; when writing alternatives.

**Double Quotes ("")**: Use it when first announcing a new term, quoting a person, when turning a word that is not a noun into a noun or when a word or sentence isn't entirely true/accurate.

**Single Quotes ('')**: Use it in double quotes, they work the same as double quotes.

**Apostrophe (')**: Use it when contracting a word (combining two words into a smaller word [e.g: don't = do not]), when showing possession (it should be followed by an s) or forming plurals for letters, number and symbols.

**Question Mark (?)**: Use it after a sentence that is any type of question.

**Exclamation Mark (!)**: Use it when a sentence has emotional intensity with high energy—the exception being sadness and any sub-types of it as sadness isn't very energetic—(When a sentence doesn't have a clear emotion to them and an exclamation mark is still used then: it means excitement).

**Interrobang (?!/!?)**: Use it when a sentence is a type of question with emotional intensity; essentially a combination of the Question Mark and Exclamation Mark (it usually describes shock/surprise).

**Tilde (~)**: Use it when a word(s) is an approximation or in dialogue/monologue to indicate a sing-song/playful/teasing/flirty tone.

**Asterisk (\*)**: Use it before a word(s), clause or sentence to imply that there are important caveats to that word, clause or sentence.

> [!Note]
> Sub-topics can be defined loosely (in parameters) but generally they are topics inside a main topic
